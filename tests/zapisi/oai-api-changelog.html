Oct 30
Update
v1/agents
v1/agents/sessions

You can now update the tools in an existing session in the Agents API public beta. Updates replace the full tool list. Function tools and MCP servers change on the next model call; built-in tools change by the next turn.

Context compaction now runs in the background by default. Set compaction.async to false for blocking compaction. Background compaction may increase token usage.

Added opt-in experimental time awareness. Set experimental.time_awareness to true to give the model periodic current-time reminders. It is disabled by default. See the agent configuration reference for compaction and experimental settings.
